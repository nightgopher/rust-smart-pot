## 四、下单节奏

```
今天      下单全部硬件（2~3天到货）
第3天     硬件到 → 阶段一：接电路、测水泵（不需要植物）
第3天     当天下单薄荷（2~3天到货）
第6天     薄荷到 → 阶段二：传感器校准
```

## 五、下单前最后确认 3 件事

1. **ESP32 选 38 针版本**（引脚多，接传感器不挤）
2. **土壤传感器认准"电容式"**——商品图是整片绿色 PCB、无裸露金属探针的才是
3. **水泵电压和电源匹配**（5V 水泵配 5V 电源，别买 12V 的）
